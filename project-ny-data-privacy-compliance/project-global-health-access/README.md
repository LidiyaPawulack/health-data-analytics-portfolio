# Global Healthcare Accessibility & Outcomes (2025)

## Overview
This project explores the relationship between healthcare accessibility and population health outcomes across countries, focusing on disparities between high- and low-income nations.

## Data Sources
WHO, World Bank, UNICEF, OECD, and CDC (public global health datasets).

## Methods
Descriptive statistics, z-scores, correlation analysis (Pearson r), and data visualization.

## Key Finding (High-level)
Countries with greater healthcare access and higher health expenditure tend to have better population health outcomes (e.g., higher life expectancy and lower maternal mortality).
